## 接口与配置

| 接口 | 用途 |
|---|---|
| GET `/api/v1/production-options` | 系统音色与制作方式 |
| GET `/api/v1/stories/{id}/production-context` | 实际剧本角色、旁白及场次 |
| POST `/api/v1/stories/{id}/production-tasks` | 明确提交制作，重复提交复用任务 |
| GET `/api/v1/production-tasks/{id}` | 后台状态、实测时长与预览 |
| POST `/api/v1/production-tasks/{id}/retry` | 显式恢复，复用原素材 |
| POST `/api/v1/production-tasks/{id}/reviews` | 同版本、同视频哈希的审核及原断点回写 |
| GET/HEAD `/media/{id}/{file}` | 指定制品的时效签名链接、文件哈希校验和Range/206 |

业务接口需要本机会话，媒体签名只授权一个任务的指定文件。服务只监听127.0.0.1。音频Key已用Windows当前用户DPAPI加密保存在被Git忽略的运行目录，不进入前端、源码、成片或审核记录。更换时使用隐藏输入：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\ops\my-legend\Configure-AudioModel.ps1
```

制作进程独立运行，关闭页面不会撤回模型请求；失败后显式恢复。更换音色的新制作版本会再次消耗额度，不承诺无成本撤回已提交推理。
