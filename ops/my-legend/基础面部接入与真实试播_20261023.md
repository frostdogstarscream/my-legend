## 接入约束与版本策略

前端继续以 ES2020 编译，未引入 `Array.at` 或新平台依赖。`LifeScript 0.3` 保持原结构，新增面部信息放在预览顶层的 `face` 中。默认关闭；旧预览缺少此字段时沿用原生动画。明确勾选并保存的新预览才启用。

`face-basic-v1.json` 是保留的不可变 Profile 集合，默认版本由后端显式固定为 SHA-256 `ea5b794b7a6bd9bee3db0459019e4fcb3d3e6b26523166a7d55c4e011a704ada`。Profile 同时绑定演员 revision、asset_id、源文件名、原始骨骼哈希及转换后的骨骼哈希。预览嵌入完整 Profile 快照、哈希、算法版本 `basic_face/1`，并绑定成品、来源版本、目录、音频、时间轴。

后续修改参数或映射需新增 Profile 文件与版本，保留旧文件，并显式决定是否切换默认版本；不能覆盖 v1 或重解释已有算法版本。再次保存启用面部的旧预览时传回其 Profile 哈希。未知 Profile 哈希拒绝保存；历史预览读取返回原有内容，浏览器校验快照和素材后执行。

渲染仍使用经过内容哈希校验的实际资源。每帧顺序为 setup pose → 原生身体动画 → 允许的面部附件覆盖 → 世界变换与网格。面部计算只使用音频绝对 sample frame，不累计墙上时间或帧数。

| 能力 | 本轮行为 |
|---|---|
| HK416 两态口型 | 仅自己的对白区间内使用 mouth1 / mouth2；280 ms 周期，开口窗 75–215 ms，句首 70 ms、句尾 75 ms 闭口。区间外恢复原生附件。 |
| HK416 眼睛 | 保留原生眨眼。 |
| AK15 眨眼 | 每 3.7 秒一次，首次偏移 0.42 秒，闭眼 115 ms；闭眼窗之外恢复原生附件。 |
| 允许动作 | idle、walk、sit。 |
| 保护动作 | lie、pick 及其他未列入动作全部使用原生面部。 |
| 其他演员 | 没有精确匹配 Profile 时给出诊断并使用原生动作。 |

口型依据对白时间区间作节律开合，未进行音素识别或音量分析。AK15 的闭眼附件为 Leye1 → eyeR5、Reye1 → eyeL5，名称看似左右交叉，已经在实际骨骼与图像中检查。

## 独立降级与诊断

- `FACE_DISABLED`：Profile 内容哈希、算法版本或音频等绑定错误，整套面部关闭，身体与原音频继续。
- `FACE_PROFILE_UNAVAILABLE`：单个演员的版本不匹配或缺少 Profile，仅该演员使用原生面部。
- `FACE_ACTIVE`：附件已在当前渲染骨骼中找到，面部能力可以执行。
- `FACE_RUNTIME_FALLBACK`：附件缺失、覆盖失败或面部网格异常，该演员面部停用并恢复原生附件；完整姿态和网格在同帧重新计算。

界面显示本次载入期间去重后的面部诊断记录，所以发生故障后可能同时看到此前的 `FACE_ACTIVE` 和后续 `FACE_RUNTIME_FALLBACK`。恢复保存版本重新加载后会重新检查。
