## 朝向规则

朝向作为预览顶层 `dialogue` 保存，使用 `legend_dialogue_track/1` / `dialogue_facing/1`。原 `LifeScript 0.3` 未扩展；没有此 sidecar 的历史预览继续原来的朝向计算。

新界面编排默认启用双人关系；恰好两名演员可见时，按当前水平位置互相面向。目标不可见或两人位置相同时保留身体朝向；三名可见演员不猜测对白目标，可通过人工轨道指定。

**已确认的产品约定（2026-10-23）：左右转向、转身及背对关系沿用水平镜像表达；无需新增背面素材，也无需制作转身过渡动画。这两项不列为待办或验收缺项。** 人工“转身”仍按区间开始前的朝向翻转一次，默认双人关系及其他人工修正规则不变。

优先级为：人工朝向区间 → 正在执行的移动方向 → 剧本朝向区间 → 人工放置指令中的朝向 → 默认双人关系 → 原生朝向。离场不会被默认“看向对方”拉回；新编排的离场选取靠近角色当前站位的一侧边缘，以减少横穿另一名演员的情况，仍执行原有路径占用检查。

人工编辑支持：

| 模式 | 行为 |
|---|---|
| 面向谁 | 按目标演员的当前站位确定左右。 |
| 朝左 / 朝右 | 在指定区间内固定方向。 |
| 保持 | 冻结区间开始前一采样帧的方向；从零开始时使用当时的默认关系。 |
| 背对谁 | 使用远离目标演员的一侧方向。 |
| 转身 | 翻转区间开始前的方向，不累计每次渲染的翻转。 |

区间均采用 `[start_frame, end_frame)`。人工区间结束后恢复当时有效的剧本、移动或默认规则；前后定位从绝对时间重建。

剧本编译识别背对、转身/转过身、面对/面向/转向、朝左、朝右。来源使用原始台词与实测事件时间锚；否定、意图、疑问、转述、多个主体或不明确目标给出诊断，不强行分配。连续子句可沿用刚确认的主体，避免把上一句宾语误认为转身主体。同一时间锚上已有朝向且又出现后续转身时，后者因缺少独立时间锚给出 `FACING_SHARED_ANCHOR`，可在简表中手工划分区间。自动覆盖延续至该演员的下一条剧本朝向或音频结束。

## 逐角色表情核对与眨眼优先级

本轮在真实骨骼上并排渲染两名演员各 5 组眼睛附件。语义依据实际显示核对，没有沿用附件包中未经核对的 happy 标签。

| 演员 | 挤眼（强调） | 惊讶（圆眼） | 闭眼 |
|---|---|---|---|
| HK416 | eyeL1 → eyeL3；eyeR1 → eyeR3 | eyeL1 → eyeL4；eyeR1 → eyeR4 | eyeL1 → eyeL5；eyeR1 → eyeR5 |
| AK15 | Leye1 → eyeR3；Reye1 → eyeL3 | Leye1 → eyeR4；Reye1 → eyeL4 | Leye1 → eyeR5；Reye1 → eyeL5 |

2 号附件语义不明确，不在可选表情中。3 号是明显挤眼，不能仅凭形状确认“高兴”；因此 UI 使用“挤眼（强调）”。4 号为圆眼惊讶。Profile 标记为 `visual_checked`、`human_accepted: false`，表示本轮实际渲染核对，仍待用户审美与剧情适配验收。

优先级为：保护动作/隐藏状态 → 闭眼 → 表情 → 原生面部。手工闭眼区间、HK416 原生闭眼和 AK15 程序闭眼都可覆盖当前表情；闭眼结束后重新计算该时刻的表情。表情结束后回到原生眼睛。HK416 原有对白两态口型继续独立运行。lie、pick 及白名单外动作完全保留原生面部。

新 Profile 文件 `face-expressions-v1.json` 使用 `expression_profiles/1` / `expression_face/1`，固定哈希 `e350412238956fde7ce8774e32e5ff7d1bd4ece2cc9f8c69b0253fc804307da1`。旧 `face-basic-v1.json` 和 `basic_face/1` 行为保持不变。后续改变含义或参数须保留旧文件并新增版本。

## FaceTrack 编辑和保存

点击“启用表情与手工轨道”会从当前草稿保存一个采用新 Profile 的版本。界面可添加/删除表情或手工眨眼、选择演员与已核对语义、编辑起止时间、启用或停用每条指令。修改后点击“应用并预览”生成新版本；同一输入得到相同哈希。

FaceTrack 使用 `legend_face_track/1`，绑定成品、来源版本、音频、时间轴、目录、采样率、总帧数、演员实例/角色/素材版本和 Profile 哈希。朝向轨道使用相同来源及演员绑定。未知类型、字符串开关、重复 ID、非法时间、过期绑定、未核对的演员或表情均拒绝保存。表情与眨眼可重叠；同一演员同类区间不可重叠。人工朝向可覆盖自动朝向，同级朝向不可重叠。

导出采用 `legend_performance_draft/1`，带原 stage、开关、Profile 哈希、朝向和 FaceTrack。继续兼容旧 LifeScript 0.3 及 `legend_face_draft/1` 导入。原生脚本导入保留原生关系，避免隐式升级。关闭一个能力后保存的新版本不携带其轨道；旧版本可恢复。重新自动编排会重建两个轨道，已有人工版本从历史恢复。

轨道校验失败时保留已经应用的版本和画面。浏览器准备阶段的朝向绑定错误只回退原身体朝向；面部错误继续沿用独立降级。源音频与字幕不因编辑轨道而重新生成。
