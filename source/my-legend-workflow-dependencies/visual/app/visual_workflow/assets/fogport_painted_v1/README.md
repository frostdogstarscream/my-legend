# 雾港非像素二维插画素材 v1

2026-10-12，按用户最新要求，背景、人物与网页渲染均改为非像素风格。新版本独立保存，历史像素预览不覆盖。仅网页适配。

内置 imagegen 生成 background.png 和 characters.png，人物原稿随后用同一工具进行透明背景清理。未引用第三方角色。人物仍为临时视觉设计，不构成剧情事实。

背景提示词：16:9，非像素、精细二维手绘冒险游戏电台室内；玉绿墙面、深木地板，左窗雾港冷蓝暮色，后墙电台与卷盘、台灯、书架、木门；下半画面留出立绘移动区域；无人、无文字、无标志、无界面。transparent_background=false。

人物提示词：透明横排三人物图集，等宽三格、完整全身、脚底对齐；非像素、非Q版，平滑线条和手绘阴影；沈砚黑发深蓝外套，苏棠短发赭黄工作服，老秦灰发短灰须棕色外套；统一约6.5头身比例，站姿空手，无文字道具。transparent_background=true。

清理提示词：保留人物身份、衣着、姿势、尺寸和三格位置；去除背景渐变、光晕与地面阴影，保留人物边缘和完整脚部，输出真实透明 alpha，不绘制棋盘背景。transparent_background=true。

渲染：平滑采样，非像素字体，高清头像画布；立绘仅坐标平移，不用步行动作帧。背景和人物 SHA256 随计划、预览和交付版本保存。演示仍含两段标明为效果演示的移动，不属于原剧本；34.8秒，无配音。
