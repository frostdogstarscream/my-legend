# 雾港电台背景 v2

由内置 imagegen 生成，未覆盖旧背景，作为环境效果设计，不据此确定剧情地点细节或人物门内外关系。角色仍复用 fogport_v1。

生成提示词：16:9 横向、精细16位像素RPG电台室内，无人物；木地板与深玉绿墙面，左侧窗外雾港，后方靠墙电台设备、卷盘、书架、台灯和木门；冷蓝窗光与暖琥珀灯光；下半画面留空作为人物平移舞台；无文字、标志或界面。

完整使用参数：transparent_background=false。输出按原图保存为 background.png，不修改生成图片。背景 SHA256 进入计划和版本记录，冻结时再次检查。当前只适配网页。

演示输入 fogport-simulation-v4.json 额外包含两段带 demo_ 前缀、source_ref=layout_demo_only 的平移事件，不属于原剧本；界面明确标注效果模拟。仍不提供 MP4 导出。
