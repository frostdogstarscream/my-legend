# 素材和界面对应关系

源设计：[指尖传说](https://www.figma.com/design/HFFS73txWzLko3LrkXr83v?node-id=5-124)。源画板为 `5:125` 登录页、`5:342` 国风工作台。PNG 是 Figma 返回的原始图片填充，不是完整界面截图；SVG 是 Figma 返回的矢量素材，根尺寸保持原文件。

| 素材 | 设计用途 | 实现位置 |
| --- | --- | --- |
| `login-background.png` | 登录插画背景 | `pages/login/index.vue` |
| `home-background.png` | 国风背景、示例故事小封面 | 首页、功能页头部、示例作品 |
| `new-story.png` | 新建故事插画 | `StoryCard` + `IllustrationCrop` 的 `new` 区域 |
| `continue-story.png` | 继续故事插画 | `StoryCard` + `IllustrationCrop` 的 `continue` 区域 |
| `characters.png`、`shop.png` | 两张小卡片的插画条 | `IllustrationCrop` 对应显示区域 |
| `avatar.png`、`ai-avatar.png` | 用户头像、AI 伴读头像 | 首页、我的、演示角色 |
| `feather.svg` | 品牌金色羽毛 | `BrandLogo` |
| `account.svg`、`lock.svg`、`gift.svg`、`eye-off.svg` | 登录表单图标 | 登录页 |
| `check.svg`、`check-small.svg` | 账号记忆、同意提示勾选图标 | 登录页 |
| `notification.svg`、`settings.svg`、`microphone.svg` | 用户操作与伴读入口 | 首页 |
| `home.svg`、`create.svg`、`stories.svg`、`characters.svg`、`profile.svg` | 底部导航 | `AppTabbar` |
| `status-network.svg`、`status-battery.svg` | 原型设备状态栏 | 保留源素材；App 使用真实系统状态栏，不重复绘制 |

插画显示区域按 Figma 的局部位置和比例实现，外围圆角在容器上裁切。按钮、标题、描述、进度和会员信息由独立组件绘制，不从图片中提取。角色商城展示区为新增壳子页面，复用原型的商城插画条。

普通中文使用系统字体；品牌和固定卡片标题使用下载的 Noto Serif SC 字体子集，标语使用 Ma Shan Zheng。动态名称缺少的字形由系统回退。字体来源与许可证在 `src/static/fonts/`。

运行 `npm run check:assets` 可以检查 25 项图片/矢量素材非空、SVG 根尺寸和字体格式，输出文件大小及 SHA-256。手机尺寸下的截图在 `evidence/`，与 Figma 渲染分开保存。
