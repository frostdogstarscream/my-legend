# 我的传说 v0.2.0 验收记录

日期：2026-10-15。基于现有 v0.1.0 工程扩展，历史源文件快照见交付目录 `baseline-v0.1.0.zip`。

## 已验证

- 产品品牌、网页标题和清单改为“我的传说”；12 个路由存在。
- `npm run type-check`、28 项 Vitest 测试通过；测试覆盖旧草稿保留、生成任务恢复/失败重试、重复兑换幂等、余额不足、时间轴边界，以及原 HTTP/会话行为。
- H5、App 资源、微信小程序三种目标编译通过。资源路径与实际输出另行检查。
- 浏览器在 393 × 852 检查登录、首页、故事列表、作品详情、演绎、创作、生成完成、阅读、角色、角色详情、我的、商城。
- 点验故事→演绎、角色对白联动、上一句、播放暂停、倍速与横屏进出。
- 点验新建灵感、选两个角色、生成演示、完成后进入详情、阅读下一章、字号切换并刷新保持。
- 点验角色详情带入创作、搜索空结果、我的设置弹层、商城兑换确认。兑换幂等与余额不足由单元测试覆盖，没有进行真实支付。
- 演绎页首轮发现播放控制被底栏遮挡，已修正区域高度和 H5 顶部安全区。复测播放控件底边约 762 px，底栏顶边约 786 px，首屏全部可见。

截图和浏览器记录位于 `docs/evidence`。生成演示留下的一份“晨光里的来信”是测试示例，旧用户草稿未清理或覆盖。
