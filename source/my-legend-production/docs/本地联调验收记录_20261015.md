## 修复和兼容处理

声音任务规划函数会在 text 和 sound.description 同时存在时发生重复关键字错误。适配器已改为 sound.production_description，保留原文与需求，没有修改原声音制作代码。

视觉原包固定了 Linux Dart 路径。在隔离副本中只增加可执行文件与 package-config 的路径注入，保持原 Dart 模型、规则编排和求值器。补丁及源码哈希在 dependency-lock.json 中记录；原 ZIP 未改变。

旧 joint_v02 的身份与事件集合限制保留。新的 my-legend.joint/0.3 区分声音旁白身份与视觉叙述、声音独有层和视觉动作，不删除身份或伪造音轨来凑集合。

原声音混音为 201600 帧、48kHz、PCM24，共 4.2 秒。原稿最后明确等待 500ms，因此派生混音追加 24000 帧静音，总长 4.7 秒。派生保持 PCM24，逐样本确认原有音轨未改变；PCM16、PCM24、浮点音频均有自动化检查。早期不同位深的调试输出只保留为历史证据，最终采用 local-004。

HTTP 服务支持 Range/206，使浏览器可以定位 WAV 和 MP4；仅监听 127.0.0.1，并拒绝目录列表及越界文件读取。
