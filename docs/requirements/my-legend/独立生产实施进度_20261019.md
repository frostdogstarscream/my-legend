# 我的传说独立生产实施进度

日期：2026-10-19。范围与完成标准继续遵循《独立生产实施计划_v1.0_20261019.md》。本记录不是最终验收报告。

## 已落地的代码

生产包 `source/my-legend-production/src/my_legend_production/production/` 已实现：

- 严格输入协议、幂等键、输出依赖图、制品哈希和来源版本约束。
- PostgreSQL 独立命名空间、后台领取、租约与心跳、取消、截止时间、恢复和部分结果。
- 外部调用意图、预算预留、累计用量观察和结算。供应商结果不明时阻止自动重复提交。
- 新生产 API 的 GET 只查询。请求尚未配置的模块在创建任务前被拒绝。
- 故事适配明确记录自动策略或用户确认，保留大纲与来源版本；原生模型调用前检查总任务状态、截止时间、阶段调用上限和修复次数。
- 独立声音子进程复用原声音工作流和缓存，执行文件哈希、波形帧数、采样率、声道、来源事件及文本覆盖检查，交付 AudioMix、MeasuredTimeline、VoiceBindings 和 AudioReport。
- 声音子进程使用 OS 文件锁；进程仍在运行时返回待续状态。已知调用用量在失败时继续登记，未知结果进入待处理状态。
- 视觉失败后，独立声音分支仍可继续，并保留最终广播剧；总任务不会错误显示全部成功。
- 视觉上下文初版协议校验源场景、人物身份、源引用、动作覆盖、出入场和动作能力。语义是否符合原文仍需独立规划与审核，结构校验不代替语义判断。

`ops/my-legend/run_story_stack.py` 已加入独立生产迁移、Worker 和 BFF 配置；前端子进程过滤数据库和服务凭据。已在确认原队列没有活动任务、核实服务 PID 后重启本机服务，保留原 PostgreSQL 和历史制品。独立生产 Worker 已运行，五个模块已配置；生产 API 鉴权、能力查询、非法请求拒绝和不存在任务查询通过实际 HTTP 检查。这仍是本机运行，尚未公网部署。

## 视觉制作阶段新增实现

- 视觉方案使用固定提示词和独立模型请求，随后另发语义审查请求；原响应、调用意图和预算记录持久保存。错误只在预定次数内修复，未知提交结果不自动重试。
- 读取原视觉包的真实能力与素材目录，并核对依赖锁和素材哈希。立绘配置支持 enter、exit、move、wait；像素表演配置使用原执行器的 enter、exit、move、face、wait、nod、shake_head、react。复杂动作、道具和多人同步动作不能冒充已支持。
- 同一作品按人物的稳定 character_id 保存外观绑定。阶段提交前进程中断时，冻结的输入和模型响应仍可重放，不因绑定刚保存而重新规划或重复付费。
- 视觉执行复用原 Dart 编排规则，并通过独立版本的初始姿态适配在源事件边界分段。连续批次传递出入场、位置和朝向，保留每批原容量限制；107 事件/107 秒合成场景已验证。单事件自身超限及连续演员集合超限仍明确失败。详见《视觉分段与状态续接_20261019.md》。
- 动作帧按实测声音采样帧映射到统一时钟，区分真实声音与计划动作停留；语音字幕只取原台词和旁白。像素渲染保留朝向、移动、点头、摇头；react 用情绪标记呈现，不声称精细面部动画。
- 整合阶段在独立媒体进程生成 MP4、封面和 PlaybackManifest，核对来源与音频哈希并实际解码视频和音频流。当前输出仍为基础像素表演，效果待独立评价。
