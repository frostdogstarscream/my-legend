# 剧本制作前审查与第三轮试跑

## 本轮目的

前两轮真实试跑已分别暴露交付分类、声音指令长度、视觉枚举和正文可制作性问题。第二轮已有 118.92 秒真实广播剧，但没有视频。本轮为通用代码修复后的新试跑，不修改旧剧本、旧媒体或失败记录，也不把反复调试的 pilot 计为保留集验收。

## 已实现的制作前审查

仅对生产 API 中要求视觉输出的创意生成任务，在 StoryGenerate 正文生成后、声音表演标注前运行 `production_draft_audit/1.0`。普通故事任务保留原流程；导入已发布剧本保持不可变，由后续视觉审核报告缺口。

模型读取原始需求、获批大纲、正文和从锁定视觉包加载的能力，逐场逐行返回原文引用、动作解释、人物在场状态、连续性及需求保留判断。程序检查引用与覆盖、动作能力、单角色单动作、重复入场、离场后的发言、人数和跨场状态。语义判断仍依赖模型，不能替代人工内容验收。

模型必须明确报告藏在声音/对白/旁白中的当前可见动作，不能将坐下、递物、开门等改标签为等待或移动。用户或大纲要求的核心动作超出能力时，返回 `STORY_REQUIRED_CAPABILITY_UNAVAILABLE`，不删去需求。自动正文修复最多一次，包含字数约束，再做完整审查；仍不合格返回失败。制作修复、JSON 修复和时长修复共享原定故事阶段修复预算。

审查使用独立调用角色 `production_readiness_auditor`，模型配置沿用既有审核模型，避免与最终剧情审核的 operation_checks 协议混用。原始调用请求/响应保存在现有 model-evidence 中；生产事件保存正文和审查指纹、问题计数，不存凭据。没有新增人工改稿步骤。
