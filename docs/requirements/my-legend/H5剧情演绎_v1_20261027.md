视觉演员最多三位。未绑定的角色保留声音和字幕，结果持续提示未安排视觉演员。规则无需模型调用，播放直接使用已有 AudioMix。

## 编排与版本约束

新人物目录为 `spine_life_catalog/2.0`、`profile=life_v2`，独立指针为 `runtime/my-legend-spine/life-v2-current.json`。本次目录哈希：

```text
fedd58a131fe5ecdc9c4e91f55007109a8f65e4f28118aebc5da8c06affdb540
```

导入器 `ops/my-legend/prepare_character_stage.py` 读取冻结角色库的文件哈希清单，保留角色稳定 ID 和 `library_revision`，生成独立骨骼、贴图、外观与能力引用。资源以 SHA-256 存放，已存在但校验失败的内容阻止导入。

```powershell
python ops/my-legend/prepare_character_stage.py --library assets/character-library/v1 --root runtime/my-legend-spine
```

`stage-preview` 的新操作：

- `GET /stage-preview/catalog?profile=life_v2`：当前或指定哈希的角色目录。
- `POST /production-jobs/{id}/stage-preview`，`profile=life_v2`：`prepare` 只读取分场上下文；`compile` 生成基础编排并保存；`validate_and_save` 校验草稿后新增版本。
- `GET /production-jobs/{id}/stage-preview/{sha256}`：校验归属、文件哈希、资源目录和来源后恢复保存结果。

上述路径均位于 `/api/v1` 下，沿用现有登录和作品归属校验。

结果为 `spine_stage_preview/3.0`，包含 `scene_track`、`scene_bindings`、`coverage`、`coverage_decisions`、`expression_track`。舞台指令继续使用已有 `legend_stage_script/0.3`，移动指令可记录具名 `target`。这是一项已完成配音作品的演绎出口，不改写旧像素 `VisualTrack` 或原制作任务状态。

场景时间以原文顺序与实测事件起点确定；背景音尾音不能延长上一场。缺少锚点、倒序、对白跨场、遗漏映射、演员版本失配、跨场动作、非法位置、错误目标或演员路径冲突均阻止保存。物件移动限于已经布置好的脚部通道，不提供任意二维寻路或自动家具碰撞建模。

播放器只使用 `HTMLAudioElement.currentTime` 取样，按绝对时间重建当前场景与人物状态。全部本次使用的场景和演员资源在应用前准备好；新资源应用失败时保留原舞台。场景切换直接执行，无转场动画。已修复浮点乘法使 `20.24 × 48000` 落到上一帧的问题。

## 状态与遗漏

| 状态 | 含义 |
| --- | --- |
| `needs_attention` | 存在待校正或能力不支持的原文动作；已支持部分可以预览。 |
| `preview_ready` | 没有未处理项，尚待人工确认；可能包含已经明确记录的省略。 |
| `confirmed` | 人工点击确认，且没有动作省略或未绑定视觉角色。 |
| `confirmed_with_omissions` | 人工确认版本仍有明确省略或未绑定视觉角色，持续显示差异。 |

“确认”是编辑流程中的操作记录，不能替代独立视觉验收。自动化验证曾测试确认分支，生成 `6167c05694e9052972beb9da4038f5b3549c102dbe9601042d83532a0555fec3`；该版本只是测试记录，不作为人工验收证据。主入口已恢复至 `b85a1dba…` 的 `preview_ready` 版本。

新布局的坐家具、拿取、翻书、翻找、复杂舞蹈和说话口型未自动执行。未知 action 文本列为不支持；对白和旁白只对已知动作表达进行规则识别，不能视为开放式语义理解。无法执行的动作可以记录“本版不演出”，不能用待机或其他基础动作标为已完整演出。
