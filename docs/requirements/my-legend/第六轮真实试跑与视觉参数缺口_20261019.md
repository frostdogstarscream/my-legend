## 视觉失败原因与通用修复

首个方案同时包含非法情绪枚举和多个动作字段冲突；原反馈只先暴露枚举错误。第二次方案修正枚举后仍给 enter/exit 填写 target_anchor，给 move 填写 target_role_id，给 face 填写 target_anchor，并给非 react 动作填写 emotion，最终触发 `VISUAL_MOVE_TARGET_INVALID`。

已把动作字段约束集中为共用规则，供运行校验、规划 Schema 和错误反馈共同使用：move 必须选择锚点；face 在方向与目标角色中二选一；enter/exit 的路径由执行器确定；只有 react 使用 emotion/intensity。反馈从原始 JSON 收集全部独立字段冲突，即使同时存在枚举错误也不会漏掉其他问题。不会自动删除错误字段或改写动作。真正不支持的动作仍停止制作；可修复的目标字段错误单独标记，不再与执行能力缺口混淆。

视觉相关回归 38 项通过，报告 `runtime/my-legend-story/tests-visual-parameters-20261019.xml`。另增加明确标记为 `cached_downstream_diagnostic` 的冻结诊断范围，默认新创意验收要求保持不变，诊断结果强制 `new_input_acceptance_eligible=false`，10 项验收工具回归通过。
