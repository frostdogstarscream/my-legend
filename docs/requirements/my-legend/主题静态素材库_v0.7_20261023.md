# 121 项主题静态素材库 v0.7

本文描述可复用素材库，当前已从中编排出 [v0.8 的 15 套固定场景](固定主题场景_v0.8_20261023.md)。完整文档入口见 [导航与准备顺序](视觉演绎与场景文档导航_20261023.md)。素材、离线预览和 ZIP 存于本机忽略目录，未随源码发布到 Git。

本轮范围：可调用素材包，包含原始图片、主题分类、来源索引与离线预览。后续再搭建固定场景布局；本轮不扩展家具互动。

## 交付状态

- 121 项已命名分类均生成独立 `manifest.json` 和预览页，并通过配置中的分类字段建立对应关系。
- 117 项在当前冻结配置中的静态组件齐全。4 项共缺少 25 个静态组件：海报 22 个、精英徽记 1 个、纪念 1 个、年货街 1 个。
- 237 个类型 2 的非静态组件引用单独保留；没有把 Spine 图集当作独立家具图片，也没有生成替代图冒充原图。
- 本地宿舍静态索引 7,827 条记录全部读取、PNG 解码并验证索引哈希。去重存储 6,835 个图片文件，共 520,682,689 字节。121 项清单合计关联 3,721 条展示图片记录；重复来源、辅助通道和未归入这些配置的资源仍在完整索引中保留。
- 每个主题保存家具名称、资源代码、配置中的拆分顺序、图片尺寸、透明范围、来源包和对象 ID，以及原始排序、偏移、旋转字段。
- 原始 PNG 字节保持不变，辅助 Alpha 通道单独归档，不自动合成。分类标签中的墙面、座椅、桌子等是检索提示；游戏配置的原始 `type` 另行保留。

## 本地使用

根目录：`runtime/my-legend-spine/theme-library/`。双击其中的 `index.html` 可离线查看；无需登录、运行 H5 或联网。整个目录或提供的 ZIP 可以迁移到其他位置，内部链接使用相对路径。

```text
theme-library/
  index.html                 当前版本预览入口
  current.json               当前目录哈希指针
  README.md                  调用说明
  content/<sha256>.png        原始图片，按哈希去重
  catalogs/<catalog_hash>/
    catalog.json             主题、资源、文件及来源完整索引
    index.html               固定版本预览入口
    verification.json        原图保护与导入验证
    source-hashes.json        7,827 条源图哈希
    evidence/                两张 STC、schema、具名行与名称/图片索引
    themes/theme_000006/
      manifest.json          该主题的家具、分件、缺口、动态依赖
      index.html             该主题的图片预览
```

稳定主题 ID 示例：`theme_000006` = LOFT，`theme_000010` = 咖啡店，`theme_000060` = 幽灵古堡。ID 来自配置中的分类 ID，目录版本变化时不因排序改变。

调用时先固定 `catalog_sha256`，再读取主题清单。使用 `asset_ids` 获取展示图片，`auxiliary_asset_ids` 是单独的辅助通道。图片的 `path` 相对于素材库根目录；不要把它当成相对于主题 JSON 的路径。

```python
from pathlib import Path
import json

root = Path('runtime/my-legend-spine/theme-library')
version = json.loads((root / 'current.json').read_text('utf-8'))['catalog_sha256']
release = root / 'catalogs' / version
catalog = json.loads((release / 'catalog.json').read_text('utf-8'))
theme = json.loads((release / 'themes/theme_000006/manifest.json').read_text('utf-8'))
images = [root / catalog['assets'][key]['path'] for key in theme['asset_ids']]
assert all(path.is_file() for path in images)
```

预览 API 也提供三个只读接口，复用现有登录鉴权：

```text
GET /api/v1/stage-preview/theme-library?catalog_sha256=<版本>
GET /api/v1/stage-preview/theme-library/themes/theme_000006?catalog_sha256=<版本>
GET /api/v1/stage-preview/theme-library/assets/<图片sha256>?catalog_sha256=<版本>
```

第一个返回主题摘要；第二个返回主题清单及其图片元数据；第三个仅返回指定版本白名单中、文件哈希检查通过的原始 PNG。接口不会修改场景、故事、音频或素材文件。

## 维护与复现

```powershell
# 使用安装了 Pillow 的 Python；来源目录只读。
python ops/my-legend/prepare_theme_library.py --library <分类素材库目录> --offline <Android_Offline_20261023目录>
python ops/my-legend/verify_theme_library.py --report output/theme-library-verification.json

# 可选：生成新名字的离线 ZIP，不覆盖已有包。
python ops/my-legend/verify_theme_library.py --archive <新的ZIP路径> --report <验证报告路径>
```

新增源文件时，更新源索引并运行构建器生成新目录哈希。历史目录保持不可变，原来固定旧版本的调用不会被重写。不要仅删除缺口记录或将 `static_status` 手工改成完整；应补充能够通过来源与哈希校验的图片。
