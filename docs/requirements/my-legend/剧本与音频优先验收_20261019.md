# 剧本与音频优先验收

日期：2026-10-19。用户明确要求暂停视觉方面，先完成音频和剧本验收，演绎目标可能调整。本记录覆盖此前实施计划中当前执行顺序，不删除历史视觉实现、制品或失败记录。

## 当前范围

推进：创意输入 → AI 大纲及剧本 → 结构化交付 → 音色绑定 → 真实配音及音效 → 实测时间轴与广播剧 → App 阅读和收听。以独立 API 和后台 Worker 完成，生产期间不靠开发会话手改内容或逐页推进。

暂停：视觉方案模型调用、视觉执行、视频合成、视觉素材完善、演绎保留集及其验收。已经准备的 `holdout-v1-20261019` 为视觉范围案例，保持未运行，不作为本阶段验收集。新视觉复测 `visual-cache-20261019-05` 未创建、未提交。

新请求仅使用 outputs=[script,audio] 或 [script]。现有 stage_graph 对前者仅建立 story 和 audio 两阶段；不触发 visual_plan、visual_render、integrate。故事服务的视觉能力审查也只对包含 visual 的请求启用，因此本阶段不因旧像素素材不支持某个动作而删改剧情。既有音频能力约束和声音输入校验继续生效。

## 已确认基线

- 数据库只读检查：15 个总制作任务全部终态（2 succeeded、13 failed），没有 queued/running 制作任务；故事规划和正文子任务也全部终态。
- `pilot-20261019-14` 的故事及音频阶段成功，总任务因视觉预检失败。其 91.88 秒音频、34 个来源事件和实测时间轴技术检查通过；App 保留可读剧本和可听广播剧，音频自然播放到结尾。
- 该基线证明已成功的剧本/声音不会因视觉失败而隐藏；不能把原总任务改判完整成功，也不等于本阶段所有新输入已验收。
- 人工内容审阅和听感评价仍未完成。历史费用按原调用账本保留；暂停视觉不回写或抹去已发生的调用。

## 本阶段验收标准

| 项目 | 检查内容 | 证据 |
|---|---|---|
| 剧本内容 | 符合创作要求、人物身份稳定、因果和结局完整；对白/旁白/音效/动作区分清楚 | 原始请求、大纲、结构化剧本、审查记录；人工审阅另列 |
| 结构化交付 | 角色、场景、行号和来源版本可追溯，无事件丢失、重复或错配 | StoryDelivery、RenderManifest、逐项覆盖检查 |
| 真实声音 | 配音与音效有供应商调用及真实媒体，声音与角色绑定稳定 | 调用账本、VoiceBindings、音频素材及哈希 |
| 时间轴与混音 | 使用实际采样帧，无截断；素材对应原台词，动作停留与实测音频明确区分 | MeasuredTimeline、AudioMix、媒体审计 |
| 独立运行 | 冻结版本从 API 提交到剧本/声音结果齐备，有限修复及费用可追溯 | 冻结清单、任务事件、全部成功与失败记录；独立性审计 |
| App 使用 | 阅读剧本、播放/暂停/进度、退出再进入仍找到作品；失败不隐藏已成功结果 | H5 操作证据；Android 后续单列 |
| 效果评价 | 故事可读、声音可懂、角色辨识、情绪、音效音量及停顿合理 | 人工阅读与听审意见，不用技术通过代替 |

先进行一条只请求剧本和音频的新输入独立试跑，再冻结六例面向故事和广播剧的保留集。保留集不沿用已针对性调试的试跑输入，不挑选成功案例计算通过率。目标时长沿用现接口支持的 90 秒，实际时长按音频记录，不截断结局来凑时长。

预算沿用已有用户授权：真实调用不设金额上限，每例仍限制 80 次供应商调用、1800 秒、每阶段最多 2 次共享修复。只推进本机链路，部署与手机测试环境以后确定。
