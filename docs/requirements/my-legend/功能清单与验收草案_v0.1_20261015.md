# 我的传说功能清单与验收草案

2026-10-19 范围更新：独立生成剧本、广播剧、视觉表演和统一任务的当前实施顺序、能力边界及无人介入验收，见[独立生产实施计划](独立生产实施计划_v1.0_20261019.md)。下表保留历史功能拆分；其中自动视觉制作后置的安排由新计划更新。

日期：2026-10-15。与[产品需求草案](我的传说产品需求草案_v0.1_20261015.md)配套，作为范围评审和后续任务拆分的起点；以下验收条件是建议目标，尚未表示已经通过。

“前端演示”表示当前存在页面或本地状态；“待接入/待新增”表示仍需实现业务能力。优先级不等于开发时间顺序，依赖与发布条件按里程碑判断。

## 1 真实创作与阅读 M1

| 编号 | 功能与优先级 | 当前状态 | 需求与验收条件 |
|---|---|---|---|
| F01 | 体验身份与账号 P0 | 前端演示，真实适配未联调 | 示例体验与真实账户分离；登录失败、过期、退出和服务端撤销有明确行为；不把演示作品或余额当成真实数据 |
| F02 | 云端作品管理 P0 | 本机草稿 | 创建、改名、编辑、删除和查询由后台验证归属；另一设备可读取同一草稿；其他账户不能访问私有作品 |
| F03 | 创作输入 P0 | 名称、灵感、题材与示例选角 | 明确灵感生成和粘贴已有文本两种入口；可配置长度、角色和篇幅限制；表单离开可恢复，非法输入不创建任务 |
| F04 | 异步故事生成 P0 | 本地计时与固定示例 | 返回真实任务标识；显示排队/执行/成功/失败/取消；结果来自指定输入；离开再进入可恢复，重复点击不重复创建任务 |
| F05 | 正文编辑与版本 P0 | 未提供生成后正文编辑 | 用户修改生成内容、保存新版本、回看历史版本；后续剧本与媒体明确引用被确认的内容版本 |
| F06 | 作品工作台 P0 | 故事详情原型 | 在一份作品内进入故事、剧本、声音、演绎；未就绪内容显示真实状态和下一步；不需要重复创建作品 |
| F07 | 阅读与进度 P0 | 示例正文、本机章节/字号 | 真实章节可读；阅读位置独立保存；首页、列表和阅读页显示一致；切换作品不会串位置，跨设备同步冲突有规则 |
| F08 | 任务查询与恢复 P0 | 单次进度页演示 | 故事内可查看全部关联任务；请求失败可重查，任务失败可按范围重试；取消、部分失败和旧版本结果不误标为完整成功 |

## 2 角色与声音作品 M2

| 编号 | 功能与优先级 | 当前状态 | 需求与验收条件 |
|---|---|---|---|
| F09 | 统一角色库 P0 | 示例档案、选角与详情 | 人设、用户拥有的角色、作品中的人物和声音配置有明确关联；同名人物不自动合并；更新角色模板不改写历史成品 |
| F10 | 剧本改编与逐句编辑 P0 | 缺少专门页面 | 从指定故事版本产生分场和台词；每句说话人明确，旁白有发声角色；动作/音效说明与朗读文本分开；角色缺失时停止进入制作并给出修正入口 |
| F11 | 声音选择与试听 P0 | 入口说明，无音频 | 列出实际可用声音和样例；用户听到真实试听，确认声音与角色的对应关系；不支持的表演能力不显示为已生效 |
| F12 | 配音与局部重做 P0 | 待接入 | 返回分段任务和音频；单句失败不丢弃成功片段；重做保留旧候选，选择后更新实际使用版本；朗读文本与确认台词一致 |
| F13 | 混音与媒体版本 P0 | 待接入 | 基于选定配音、音效和实际时长形成成品；素材可追溯到内容事件；替换片段后更新时间轴，旧成品明确标为旧版本 |
| F14 | 实际音频播放 P0 | 无真实伴读 | 使用实际媒体时长，支持播放、暂停、拖动和章节跳转；中断与网络失败有提示；播放位置与阅读位置分别保存 |

声音验收同时包含程序检查与人工听审：程序核对素材存在、时长和版本；听审核对台词、人物、表达和遮挡。仅生成文件或请求成功不能作为声音合格证据。

## 3 管理与内测支撑

| 编号 | 功能与优先级 | 当前状态 | 需求与验收条件 |
|---|---|---|---|
| F15 | 使用额度与消耗记录 P0 | 只有演示余额 | 后台控制额度与并发；提交范围和消耗规则可查看；重复请求不重复记账，失败/取消的处理规则可追踪；记录与支付账本分开 |
| F16 | 最小制作管理后台 P0 | 本轮前端无对应管理入口 | 管理角色、声音、模板、素材和任务；工作人员能定位异常阶段，查看版本与制作记录，限制重试范围；客户端不持有模型密钥 |
| F17 | 内容与数据管理 P0 | 无完整业务链 | 私有作品隔离；生成和分享有内容问题处理；删除、分享撤回、缓存及媒体清理有规则；反馈带定位信息，避免暴露不必要的私密内容 |
| F18 | 终端与异常验收 P0 | 有三端编译记录 | 对纳入发布的平台进行实际登录、制作、播放、后台切换、网络中断与恢复测试；Android 安装包、小程序和 H5 分开记录结果 |

## 4 独立 NFC 角色添加验证

| 编号 | 功能与优先级 | 当前状态 | 需求与验收条件 |
|---|---|---|---|
| F19 | NFC 添加角色，是否作为首版 P0 待确认 | 历史方案要求保留，当前 uni-app 无入口 | Android 真机识别至少两种已配置角色卡；添加正确角色，同一用户重复扫描不重复添加；应用重启后仍可用；添加后创作不要求重新扫描 |

沿用历史最小范围时，不引入芯片独占账号绑定、防伪、解绑和转赠。测试要求识别信息、映射与用户角色记录可追踪；实际标签与手机的读取能力另行核验。此项可以并行验证，但不替代内容与声音链路验收。

## 6 业务对象与契约补充

| 对象 | 至少需表达的内容 |
|---|---|
| 用户与角色库 | 账号归属、角色来源、加入记录、可用状态 |
| 作品与正文版本 | 作品身份、作者、题材、确认状态、版本及当前采用版本 |
| 剧本与人物 | 来源正文版本、场景、人物标识、台词/公共事件标识、说话人与朗读内容 |
| 制作任务 | 类型、输入版本、范围、状态、阶段、错误、取消与重试关系 |
| 声音配置和素材候选 | 角色绑定、配置版本、试听样例、实际音频、实测时长、选定记录 |
| 成品媒体与时间轴 | 来源版本、媒体地址和可用状态、时长、台词/字幕区间、素材来源 |
| 阅读与播放记录 | 分开的内容/媒体定位信息、版本、更新时间 |
| 额度与消耗 | 配额、实际消耗、关联任务、幂等记录；不以客户端余额代替服务端账本 |

现有 `Story.status`、`Story.progress` 和独立的 `GenerationTask.progress` 支撑了原型，阅读与播放还有各自的本机状态。正式接口需要补齐这些对象之间的关联和持久化规则，不能把作品级百分比扩展为所有业务状态。

公共事件标识优先对齐已有制作契约的 `block_id` 等字段，客户端可以做视图适配，不重复创造无法映射的另一套事件身份。

## 7 首次用户验收用例

1. 用户体验官方样例后登录真实账号，创建一份私有作品，换设备能读取同一草稿。
2. 提交生成后离开页面，回来看到真实任务和结果；反复点击不会创建重复付费任务。
3. 修改一处正文并确认，剧本引用新版本；旧结果仍可查看，不能误认为基于新正文。
4. 检查旁白和人物分配，试听声音，生成短篇；程序检查与人工听审均通过。
5. 故意制造一个片段失败，其他成功片段保留；重试后只采用选定候选并重新确定时长。
6. 收听、拖动、退出再进入，恢复同一媒体版本的位置；阅读进度不会覆盖音频位置。
7. 在另一账号尝试访问私有作品、任务和媒体，应由服务端拒绝。
8. 如果首版纳入 NFC，完成 F19；如果纳入视频，使用真实媒体完成 F20；编译记录不代替这两项。
