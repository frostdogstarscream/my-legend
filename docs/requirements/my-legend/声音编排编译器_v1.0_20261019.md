# 声音编排编译器 v1.0

状态：契约与离线编译实现完成，尚未接入生产 Worker；真实模型编排、真实混音与人工听审待验。视觉制作继续暂停。本文承接《声音分类与编排接入》和《编排时间轴契约 v1.1》，不改变历史真实作品。

## 输入与职责

`AudioArrangement` 使用 `audio_arrangement/1.0`。绑定冻结的 StoryDelivery 原始字节 SHA-256 与 source_version_id，每行提供 episode/scene/line、原文、身份、类型、逐字依据和制作理由。编排必须按原文顺序完整覆盖，缺行、换序、修改角色或台词均拒绝。文字依据只能证明引用正确，不能证明模型理解或制作选择正确；独立语义审查仍需后续接入。

五种模式为 speech、one_shot、background、action_note、stop_sound。对白和旁白只能使用 speech；sfx/music 可选一次音效或持续背景；action 只能作为零时长说明或停声标记。停声必须指向本剧明确的 background 事件，不能凭关键词静默生成声音或把停止说明当作音效。

每行显式提供开始锚点：作品起点或任一已存在事件的 start/end，允许毫秒偏移。背景另需结束锚点。来源场景只是剧本组织边界，不自动截断背景。开始/结束节点组成依赖图，执行前拒绝引用缺失和依赖环，包括“背景结束依赖对白、对白又等待背景结束”的环。

`resolve_frames` 读取真实素材帧数。speech/one_shot 时长必须等于素材帧数，禁止为匹配目标时长裁短或拉伸对白。background 可按明确结束锚点循环或裁切。stop_sound 的位置必须等于目标背景结束帧；action_note 不引入固定 1.2 秒停留。首版不支持并行对白，冲突明确报错。

## 编译与处理来源

入口：`production/audio_arrangement_render.py::compile_arrangement`。输入为素材根目录、全新输出目录、剧本原始字节、已校验的方案对象，以及以来源三元组索引的原生素材记录。

素材进入编译前检查文件路径不越界、原始字节哈希、采样帧数、采样率、声道及有限采样值。当前钟统一为 48 kHz、单声道，输入不匹配时拒绝，不能在编译过程中隐式重采样对白。原始素材复制到新输出目录，父素材不改写。技术资源保护默认最多 1800 秒输出，与剧本软字数预算无关；不通过截断内容处理越界。

循环及裁切复用锁定的原生 `loop_asset`，保留父素材、处理修订与关键点；裁切若会丢失已确认关键点则拒绝。淡出只允许背景，长度不能超过背景区间。记录循环/裁切/淡出各层来源。对白保持原始素材哈希。

全剧一次混音复用锁定原生 `mix`，根据计划处理每层增益、对白期间背景衰减及其过渡。峰值保护为 0.95，报告记录实际峰值缩放。新增时间轴处理类型包括 faded_background、looped_faded_background、cropped_faded_background，均必须有父素材哈希。

输出：

- `arrangement.json`：规范化方案原始字节，时间轴绑定其精确哈希。后续登记制品须登记这些字节，不能重新序列化后冒用原哈希。
- `mix.wav`：整剧实测混音。
- `timeline.json`：`measured_timeline/1.1`，含完整源事件、实测帧数及零时长标记。
- `compile-report.json`：输入剧本/方案绑定、逐素材处理来源、混音参数、峰值处理及待听审状态。
- `inputs/` 和 `assets/processed/`：原样输入副本及衍生处理素材。

已有输出目录拒绝覆盖。编译失败可能留下本轮诊断目录，不将其视为成功制品；后续编排集成需通过任务账本及新的编译尝试目录管理恢复。

## 验证及下一阶段

媒体环境 36 项定向测试通过，报告 `runtime/my-legend-production/tests-audio-arrangement-20261019-02.xml`。覆盖来源绑定、错误引用、循环依赖、角色/原文变更、停声目标、对白重叠、越界、跨场混音、循环/裁切/淡出、素材哈希与元数据错误、禁止覆盖、已确认关键点保护。合成 PCM 对照实际输出，三段语音合计 6 秒，背景持续到第 4 秒，停止标记不增加时长；对白期间背景下降 12 dB，且原始素材字节未变。

上述测试没有调用供应商，不证明语义理解、真实声音效果或 App 验收通过。生产 `AudioStage/audio_job` 仍使用原 1.0 场景拼接，尚未启用本编译器；没有重载服务或提交第六轮。
