# 视觉分段与状态续接

实现版本：native_state_continuation/1.0。范围：既有像素执行器的顺序事件编排与实测声音时间轴映射，不新增剧情、动作、素材或模型调用。

## 执行规则

同一连续现场按源事件边界分批。每批保留原执行器的最多 100 个事件及 90 秒原生估算时长限制；源事件的实测时间跨度也受 90 秒批次上限约束。原生编译返回容量错误时，在事件边界继续缩小当前批次。其他编译错误直接失败，不按容量错误掩盖。

每个源事件在最终 mapping 中恰好出现一次，依旧指向 episode_id、scene_id、line_id。每批记录源范围、事件数、原生时长、计划哈希、初始状态、结束状态与执行器源码哈希。所有帧采用一个全局音频采样时钟，不逐段累加四舍五入后的媒体时长。

角色的稳定 ID、素材绑定和当前连续现场的 cast 顺序保持一致。上一批结束后的 position、direction、visible 原样传入下一批的初始姿态；临时说话状态、反应标记、走路帧和点头偏移不跨完整事件边界残留。连续批次初始状态与上一批结束状态不同则失败。

时间轴中事件之间的静默间隔使用前一事件结束后的姿态，清空字幕和临时动作；不能在间隔内提前启动后一个事件。首事件之前的静默使用初始姿态。

## 原依赖保护

原视觉依赖目录及锁文件不修改。适配器先校验固定 compiler.dart 和 evaluator.dart 的源码哈希，再在临时目录生成带初始姿态参数的编译适配。原模型校验、路径规则、碰撞检查、字幕分页、容量限制和求值器继续使用原规则。结束后清理本次临时目录。

该适配独立记录版本与生成源码哈希。若原编译源码变化则拒绝执行，需先评估并发布新的适配版本。发布包必须包含 native_segment_bridge.dart；仅将 Python 文件部署过去不足以运行。

## 已验证

- 107 个事件、107 秒的合成时间轴：分批执行，事件无遗漏或重复，每批原生时长不超过 90 秒。
- 入场、移动至非默认站位、转向、离场、隐藏后再次入场：各段状态精确续接。
- 首事件前及事件之间的静默：不会提前开始动作，已完成动作姿态保持。
- 单事件超出批次容量：明确失败，不截断事件或偷偷缩短时间。
- 原依赖源码改变：在执行前拒绝。
- 分段结果经独立 Worker 接入实际 Dart 编排、FFmpeg 编码解码和统一播放清单的本地测试通过。该测试使用合成声音及模型替身，视频为 3 秒测试制品。
- 190 项后端完整回归通过；更新能力说明及规划提示词后，15 项视觉规划、分段、整合专项回归通过，报告分别保存。
- 离线 wheel 构建和包内容校验通过；82 个锁定原依赖文件保持不变。未更改已安装 Python 环境。

## 尚存边界

一个源事件本身超过 90 秒，或原生字幕估算已超过单批容量时仍返回 VISUAL_SINGLE_EVENT_CAPACITY_EXCEEDED。当前不自动拆开该源事件；后续若支持，必须保留子片段到原事件的完整映射。

连续现场的演员集合仍最多 4 人；全作品素材演员最多 6 人。尚未支持跨批次中的半个动作状态、道具物理状态、并行动作或精细口型。真实模型的新输入成片、人工观感和 Android 真机结果另行验收。
