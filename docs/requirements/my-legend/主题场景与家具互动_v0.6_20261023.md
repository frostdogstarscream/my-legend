## 已实现

- H5 生活演绎新增 LOFT 居室、咖啡店、万圣主题及原始背景四个选择项，带分层布景缩略图。选择进入草稿，应用后才改变舞台。
- 三套均为自行布置的演绎样例。25 张原始 RGBA PNG 按索引哈希复制到本地内容存储，保留独立图层；墙面、地板、后景、按接地点排序的家具与角色、前景装饰共用镜头变换。
- 场景保存不改写原故事、音频、时间轴、身体动作、对白关系与面部轨道。旧预览不含场景字段时仍显示原始背景；原版本文件不重写。
- 每套提供 HK416 与一个固定座位的互动：0–0.5 秒待机，0.5–2 秒走近，2–6 秒坐姿循环，6–6.35 秒站立待机，6.35–8.35 秒离开，之后待机。独立入口使用 12 秒无声试演。
- 也可从真实作品创建独立家具技术草稿，保存为新预览版本。此版本静音借用原音频时钟，并显示技术说明；原音频文件及原字幕数据仍保留，不把家具动作冒充原剧情。
- UI 展开列表提供完整 121 项家具分类名称，详见 [家具主题名称索引](家具主题名称索引_121项_20261023.md)。名称索引包含通用分类，尚未逐项完成官方套装与素材映射。

HK416 `sit` 的腿部主姿态在首尾保持坐姿，实测动作时长约 1.333333 秒，属于坐姿循环。首版以原生坐姿与待机进行姿态切换，没有声称存在完整坐下或起身过渡动画；没有新增转身过渡。座位偏移始终固定于坐姿期间，未用逐帧平移伪装坐下过程。

静态 PNG 的实际透明度已在 WebGL 舞台检查。万圣幽灵的透明区域正常，无需猜测合并独立 Alpha 文件。原 PNG、骨骼、图集与旧校准文件均未编辑。

## 接口与保存

- 新增已登录可读的 `GET /api/v1/stage-preview/scenes?catalog_sha256=...`，返回 `legend_scene_catalog/1`。目录、资源与座位校准均按版本保存；25 张图片复用原 `/stage-preview/assets/{digest}` 哈希白名单接口。
- 原生活预览 POST 增加可选 `scene: {catalog_sha256, scene_id}` 和 `furniture_track`。保存结果包含相同字段，参与不可变预览哈希及 `legend_performance_draft/1` JSON 导入导出；原 `LifeScript` 结构不变。
- `legend_furniture_track/1` 的每个 cue 包含 `id, instance_id, seat_id, start_frame, arrive_frame, leave_frame, end_frame`，使用原 sample_rate。仅技术样例可启用，限定演员 ID、版本及服装与座位校准一致。
- 严格拒绝缺场景、未知座位、演员版本不符、时间越界、非整数时间、重复实例、座位冲突、与身体/位移/换装或对白朝向并行的家具编排。
- 新场景在离屏容器加载并校验，成功后替换舞台。加载失败保留上一有效舞台，原音频及字幕继续。取消场景后可恢复与旧预览相同的内容。

本次修复一个失败恢复问题：Pixi 8.16.0 的 `Application.destroy(true, ...)` 会释放全局资源池，影响同时存活的旧渲染器。改用 `{removeView:true, releaseGlobalResources:false}`，仍释放当前舞台的几何、图片纹理与画布。真实资源失败注入已验证旧舞台继续渲染。
