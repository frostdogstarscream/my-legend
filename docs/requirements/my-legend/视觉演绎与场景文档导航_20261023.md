## 源码与本地产物

Git 包含前后端实现、导入/校验/导出脚本、布局参数、测试和阶段文档。以下目录与文件按既有规则保留在本机：

- `runtime/my-legend-spine/`：演员与场景目录、原始图片、官方兼容运行时、已保存预览。
- `runtime/my-legend-spine/theme-library/`：121 项主题素材库、配置证据与离线素材预览。
- `output/my-legend-ready-scenes-v0.8-96e9c6e76202/` 和同名 ZIP：15 套固定场景的离线总览、原图和截图。
- `output/playwright/ready-scenes-v08/`：浏览器验证脚本、结果和截图。
- 模型凭据、数据库、已生成声音和其他运行数据。

阶段文档中指向 `runtime/`、`output/` 或 `127.0.0.1` 的入口是本机路径，不是 GitHub 托管下载。克隆仓库不会带入第三方素材或本机服务。需要使用者自行准备有权使用的素材及相应本地配置。

## 准备顺序

1. 按仓库首页完成前端、Python、数据库和本机 API 配置；按舞台说明准备兼容运行时、战斗与生活演员目录。
2. 使用安装了 Pillow 的 Python，从分类素材库生成基础三套场景；输入为原始分类索引与 PNG，脚本只读取来源目录。
3. 从原始素材库和具名 STC 配置导入主题素材库；运行独立校验器检查图片与主题清单。
4. 在固定目录快照齐备后，生成 15 套场景目录。通过 H5 验证后，再整理本机截图并导出离线总览。

```powershell
# 参数需替换为本机真实路径；以下命令均在仓库根目录运行。
python ops/my-legend/prepare_scene_preview.py --library '<分类素材库目录>'
python ops/my-legend/prepare_theme_library.py --library '<分类素材库目录>' --offline '<Android_Offline_20261023目录>'
python ops/my-legend/verify_theme_library.py --report output/theme-library-verification.json
python ops/my-legend/prepare_ready_scenes.py
./ops/my-legend/Start-SpinePreview.ps1
```

`ready-scene-presets.json` 固定了本次基础场景和主题素材目录哈希。若输入素材、演员版本或生成器内容不同，导入所得哈希可能不同；应复核新快照并更新布局引用生成新版本，不能直接把文件改名为旧哈希。当前固定哈希和素材版本见 v0.8 文档。

`export_ready_scenes.py` 还要求本机已生成对应的 `scene-<scene_id>.png` 和 `focus-<scene_id>.png` 浏览器截图；它负责核验和打包，不自动启动浏览器或生成截图。没有这些本地产物时，仍可在 H5 中使用生成后的固定场景目录。

## 本轮验证结论

本机浏览器已检查全部 15 套场景、15 套聚焦镜头及真实作品逐套保存/恢复；切换布景保留原音频、字幕、身体编排、对白方向和表情。122 张 PNG 按哈希校验、旧三套布置与座位保持一致，67 个历史基线文件未改变。离线总览三种预览模式可切换，390 像素宽度无横向溢出。

提交前复核：前端 103 项测试和类型检查通过；同一实现的 H5 构建通过，仍有三项既有字体路径提示。后端场景、主题接口、表情建议、生活编排、面部轨道与播放相关 153 项测试通过；素材库构建器 6 项测试通过。原战斗舞台三个演员共 620 次采样顶点有限、重复定位确定性通过。源码导出检查无凭据或大文件问题。完整逐阶段证据见各版本文档。

这些结论属于本机技术检查。用户最终视觉验收、移动端性能、APK、小程序、视频导出、自动家具交互和自动剧情选景尚未完成。
