# 产品界面整理

按本轮用户要求，将常用页面收敛到登录、角色选择、创作、故事集、播放和修改。

- 登录页改为“开始创作”，移除本机服务、模型密钥、账号开放进度等说明。
- 首页撤下商城、灵感币、通知和伴读占位入口，展示新建故事、继续故事、挑选角色；角色入口使用实际人物缩略图。
- “我的”保留故事、角色、关于与退出登录，移除会员、订单、钱包及未生效的偏好开关。
- 角色列表移除墨羽、灵墨，当前可选 31 个服装角色。旧故事的角色快照仍可读；未删除故事服务中的历史角色身份。
- 创作页删去重复的技术说明、调用说明和免责声明。仍保留角色人数、必要的填写提示及实际失败信息。
- 已完成作品不再展示制作阶段，历史版本默认折叠；制作中仍显示真实状态。
- 舞台编辑折叠剧情对应记录，撤下验收状态、哈希显示、配置导出入口和模型调用预算文案，保留场景、动作、表情和保存能力，配色与产品页面统一。
- 旧商城地址转到角色页；旧作品和播放地址继续使用。

历史界面整理使用 `work_archives` 增量表，仅影响作品列表。归档 52 条旧独立制作作品、1 条草稿恢复验收记录、3 条早期联调故事，共 56 条；作品列表保留四部完整创作。原始任务、声音、舞台文件和直达接口均保留。

归档清单与页面截图位于 `output/playwright/product-polish-20261029/`。恢复时可按清单移除对应的 `work_archives` 行；不需要重建作品。

验证：前端类型检查与 123 项回归通过；草稿、作品及角色目录相关 11 项回归通过；新增归档隔离测试通过（归档后列表隐藏、所有者直达仍可用、跨用户访问拒绝）。浏览器检查通过登录、31 个角色选择、创作绑定、四部作品列表、历史版本展开收起、实际播放及打开编辑。首页在 393×852、320×740、1366×900 下无横向溢出。本轮未新增付费生成调用。
