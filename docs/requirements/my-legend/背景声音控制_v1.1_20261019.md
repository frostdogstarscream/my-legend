## 新契约和执行语义

`audio_arrangement/1.1` 增加以下模式。对白/旁白仍只能为 speech，普通 action_note 仍只允许源 action。

| 模式 | 必需字段 | 执行及验证 |
| --- | --- | --- |
| continue_background | control_target、start | 确认明确背景在该位置仍有实际音频覆盖；不生成重复素材 |
| change_background | control_target、start、transition_end、target_gain_db | 从 start 开始线性改变振幅，到 transition_end 达到目标增益，此后保持；不能无目标、越界、重叠或声称变化但增益不变 |
| stop_sound | stop_target、start | 目标背景的结束帧必须等于本控制位置 |

源 sfx、music 或 action 都可表达背景控制，完整原文和来源 ID 保留；当前声音生成入口仍不支持新增配乐素材。control_target 必须是源顺序中更早建立的 background，不能指向对白、未来声源或不存在的行。增益以 dB 表示相对原始素材的绝对设置，不是每次累加值；多个变化按源顺序衔接并保持前一次目标值。transition_end 是事件锚点，不采用估计配音时长。

控制行自身 start=end，不推动默认静默时长。变化区间单独记录，背景仍按自身 end 结束。编译器先按真实帧数确定位置，再生成实际增益包络。为避免中间 WAV 因提高增益而先行削波，以计划中的最大增益归一化处理素材，最终在混音器恢复该增益；对白 ducking 和最终峰值保护继续生效。

时间轴升级为 `measured_timeline/1.2`：新增 duration_basis=sound_control，保留源 kind，记录 target、transition_end_frame、from_gain_db、to_gain_db；控制不声明自己具有音频哈希。被实际改变的背景标记 automated_background，并保留父素材哈希及处理修订。校验器拒绝没有控制对应的自动化素材、越界控制、冲突过渡以及未执行的停止。

适配层 sound_control 路由生成零时长原生 action 标记，不提交供应商声音任务。素材预算按方案中的真实 speech/one_shot/background 数量计算，不能按所有源 sfx 数量重复预留。局部音频重制只支持实际有素材的行；非音频控制行不能伪装成生成素材。重制真实片段后重新测量、重建背景与变化区间。

模型规划提示升级为 1.1，动态 JSON Schema 固定方案版本，并明确不同 kind 允许的 mode；JSON Schema 和后端均拒绝 sfx→action_note。独立复核明确检查背景延续、渐变方向、时机和停止对象。依旧使用已有有界修复与调用账本，不增加会话上下文或人工产物修补。
