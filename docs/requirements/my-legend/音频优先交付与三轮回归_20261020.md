# 音频优先交付与三轮回归

日期：2026-10-20。范围：我的传说的剧本、独立声音衔接层和广播剧；视觉暂停。

## 交付规则

新广播剧请求采用 `sound_workflow=sound_bridge/1`、`audio_delivery_policy=audio_first`。未指定新策略的历史请求继续使用严格规则，历史制品保持不变。

1. 剧本原文、角色身份、完整对白与旁白是交付底线。缺少配音、源版本不一致、素材损坏、时间轴无法合成仍然阻止交付。
2. 声音编排审核在有限修复后仍有问题，可以把受影响音效降级为不发声标记，保留其原始剧本位置及缺口说明。已有可执行方案时保留其他声音；无可用方案时使用按剧本顺序排列的完整配音方案。
3. 原生声音生产有明确失败、且全部配音素材齐备时，允许省略失败音效及其关联控制。原生失败报告与调用记录不改成成功；重新编译实际可用素材，最终 PCM 仍须通过结构、完整性及版本绑定检查。
4. 音效调用返回结果未知时，当前版本仍需要对账，不能直接认为失败或成功，也不会自动重复提交。这是当前交付优先策略仍保留的限制。
5. 所有省略在 `AudioArrangementEvidence` 或 `AudioReport` 中记录，App 作品详情显示提示。系统不把被省略的声音擅自认定为不重要；关键音效及真实听感仍待核对。
6. 原始声音编排与实际执行编排分别保留。运行时省略音效后新增 `AudioExecutionArrangement` 和技术交付审核记录，时间轴、编译报告与播放器绑定实际执行版本。
7. 降级成品暂不开放基于旧缓存的局部重制，避免套用不一致的声音方案。仍可从原剧本重新制作。未降级成品保持原有局部重制功能。

`technical_quality=passed` 只表示可执行、可解码和源数据绑定通过，不代表模型语义审核或人工听感验收通过。降级审核显式标注 `semantic_review=not_passed`；原有问题报告保留。

三轮合计 63 次供应商调用。两份成品的媒体完整性检查及独立 PCM 重建检查通过，重建最大误差分别为约 `1.57e-7`、`1.19e-7`。三个任务的源代码与工具冻结检查均通过，未人工恢复任务、替换案例或修改生成制品；未结算与结果未知调用均为 0。

“2/3 可播放交付”包含一份降级配音版。不能将其表述为“2/3 完整广播剧质量验收通过”。第三轮证明真实任务可以在声音方案失败后保住完整配音，但未实测触发“明确的音效供应商生成失败后选择性省略”分支；该分支本轮仅有离线验证。

### sa01：严格审核被非关键元数据卡住

任务 `3b38bde1-c85d-4fb2-b2c3-af6eafce708c`。

审核模型对第 3 场第 2 行 `action` 额外填写了 `sound` 分类。该字段只允许 `sfx` 行填写。一次原始审核与一次 JSON 结构修复均保留了这个错误，最终报 `STORY_AUDIO_REVIEW_INVALID`。复放审核 Schema 得到同一错误：`sound classification required exactly for sfx`。无声音生成调用，不能归因于音效供应商。

建议下一步对可确定无损的冗余审核字段按原文 kind 归一化，同时保留原始响应；对白缺失、角色错绑、原文不一致等问题仍不能放行。

### sa02：技术跑通，但成稿有时间矛盾

任务 `b765cfc5-0613-46d3-b176-946cb6684c77`。

开头“才刚过六点半”，同一场内又说“十八点四十五？那不是已经过了吗！”，未交代时间跳跃，因此时间逻辑不一致。建议改为“十八点四十五？只剩十来分钟了！”，本轮为保持测试证据未修改。

12 段对白和 9 份声音素材均实际生成，未省略音效。App H5 实际加载并播放至 `1:04 / 1:04`，字幕随播放推进。人工音质、角色表现及数字读音仍待试听确认。

### sa03：配音兜底生效，声音降级范围过大

任务 `48e81811-9bcf-4982-abad-a8feb4d59d17`。

声音编排的三次尝试均在第 12、24、30 行触发 `COMPOUND_CUE_NOT_LITERAL`。模型用“关闭屋内环境音”“屋外环境音继续”“停止屋外环境音”描述背景控制，这些控制说明不是相应源行的逐字摘录。编排契约因此无法构建可执行方案；本轮尚未向音效供应商提交生成。

系统随后自动保留全部 16 段真实配音并编译成片，没有人工介入或再次提交剧本。16 条声音描述全部记录为省略，其中包括剧情关键敲击声，故应标为“完整配音版/声音待补齐”，不能称完整广播剧。旁白仍描述声音线索和原因，能够读出故事，但悬疑氛围明显缺少设计所需的声音层。

建议下一步将控制操作的原文引用由程序绑定，把控制含义与原文摘录分开；优先只修复或省略不合规操作，减少全方案降为纯配音的情况。
