## 准备与运行

使用故事环境的 Python 执行模块 `my_legend_production.production.acceptance`。

```powershell
& 'D:\Code\AIToy\runtime\my-legend-story\.venv\Scripts\python.exe' -X utf8 -m my_legend_production.production.acceptance prepare --workspace D:/Code/AIToy --request D:/Code/AIToy/ops/my-legend/evidence/acceptance-pilot-request-20261019.json --directory D:/Code/AIToy/runtime/my-legend-production/acceptance/新的唯一目录
```

prepare 不请求模型。它记录生产源码、故事服务源码、启动脚本、协议、提示词所在源文件、模型配置及原依赖文件的哈希，并记录 Dart、FFmpeg、Dart 包配置和运行 Python 的哈希。只导出模型配置的允许字段，不复制密钥或加密凭据文件。

运行前必须确保 API 与 Worker 已加载该版本，并确认本次费用边界。以下命令会提交真实制作，不应在费用未确认时执行：

```powershell
& 'D:\Code\AIToy\runtime\my-legend-story\.venv\Scripts\python.exe' -X utf8 -m my_legend_production.production.acceptance execute --workspace D:/Code/AIToy --directory D:/Code/AIToy/runtime/my-legend-production/acceptance/pilot-20261019-04 --acknowledge-provider-billing
```

工具使用当前本机登录与业务 API，仅提交一次制作，随后读取状态、调用证据和媒体文件。它不替用户确认大纲，不自动恢复失败任务，不修改剧情、视觉上下文或产物。运行期间发现冻结源码变化或等待超过限定时间，会请求取消并保留失败记录。

提交意图、观察记录、结果与失败文件都以不覆盖方式写入。工具崩溃后禁止直接覆盖原目录重跑；先查明已有 job_id 或幂等键对应的任务状态，不能据观察中断推断生成未发生。

## 记录和判断

- freeze.json：输入、代码、工具链及模型配置快照，预算与允许操作。
- submission-intent.json / submitted.json：提交意图、幂等键和已知任务 ID。
- observation-*.json：只读状态及源码是否改变。
- execution-evidence.json：后台调用数量、预算、自动修复次数、恢复/取消/对账事件；不返回模型原始提示词或凭据。
- artifacts/：经服务端权限检查下载、并在本地再次核对长度及 SHA-256 的结果。
- media-audit.json：对下载副本再次核对任务归属、同版本播放清单、已登记制品、剧本事件与时间轴逐项一致性；读取 PCM WAV 的实际样本验证帧数，使用受控 FFmpeg 进程解码视频的画面和音轨及封面。禁止媒体读取网络协议。哈希正确但媒体截断、缺音轨或虚报输出也会失败。
- playback.json / result.json / failure.json：播放结果与运行结论，失败不覆盖。

媒体审计不代替模型来源、音画锚点或人工听感与视觉评价。结果中分别保留 requires_call_evidence、requires_anchor_evidence 与 pending；可解码的静音测试视频不能据此当作真实模型作品。

“源码未变”“没有恢复事件”和“文件哈希通过”不能独立证明没有会话介入。因此 session_interventions、manual_artifact_edits、out_of_band_context_injections 初始为 null，independence_attestation 为 pending；不会默认填 0。真实运行后须结合冻结运行过程审计再给结论。人工效果与设备验收也保持 pending。

## 对账与恢复

`POST /api/v1/production-jobs/{id}/reconcile` 只接受 expected_revision。不能由客户端提供“调用已完成”的状态、费用或任意上游 ID。

当前实现可查询任务检查点中已登记的 StoryGenerate 大纲任务或正文任务。只有上游进入终态且用量无未知标记时，才能结算相应调用，保留上游响应摘要哈希。对账不启动模型，不自动恢复任务。App 可先“核实外部生成结果”，核实完成后再明确恢复未完成阶段。

尚不支持自动核实的音频调用和直接视觉模型调用返回 RESULT_QUERY_UNAVAILABLE，保留原状态和证据。缺少上游 ID、上游仍在运行、用量仍未知或归属/版本冲突都不能解除阻断。

`GET /api/v1/production-jobs/{id}/evidence` 只读返回当前用户作品的调用摘要。它与其他查询一样不会推进生产。
