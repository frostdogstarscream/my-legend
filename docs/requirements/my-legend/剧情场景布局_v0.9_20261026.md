# 剧情场景布局 v0.9：合理布置、视觉层次与演绎空间

日期：2026-10-26。当前为本机 H5 实现；15 套新布局已设为默认场景目录。用户提出的“布置合理，并且兼顾美观”纳入本次布局与画面复核标准。人工最终视觉验收尚未完成。

## 调整结果

在原始 PNG 上重新编排布局，没有重绘、拉伸单件图片比例或覆盖历史场景。每套保留自己的主题、主要陈设和配色，按家具组合、相对尺度、画面主次、人物站位及通道整理。

- 家具组合有用途：LOFT 沙发与茶几组成会客区；咖啡吧区分服务台与会面桌；图书馆区分书架、壁炉、阅读座椅；博物馆展柜前保留参观空间。
- 修正局部问题：图书馆沙发不再挡住壁炉；海边小屋窗框完整显示；博物馆移去挡在展柜前的长凳；居酒屋移去重叠餐桌，并把实际为摊位的素材正确标为“外侧摊位”。原图仍保留。
- 统一基础人物比例为 `actor_scale=0.64`，本次实际演员站立高度约 192 px；重新调整南洋餐桌、阅读座椅等物件的相对尺度。
- 墙面背景与落地家具分层；落地家具按 `depth_y` 排序。人物前方保留连续通道，不再用大型前景物件挡住身体和脚部。
- 新布局人物增加轻微脚下阴影，随人物位置与镜头移动。旧目录没有 `blocking` 字段，继续沿用旧渲染行为。
- H5 新增“显示走位参考”：开关只显示参考线，不改变原作品动作、音频、站位或面部轨道。

## 提供给后续编排的空间数据

每套新增可选的 `blocking: legend_scene_blocking/1`，兼容旧 `legend_scene_catalog/1`：

| 数据 | 用途 |
| --- | --- |
| `walk_lane` | 连续横向脚部通道，归一化坐标 `[0.06, 0.80, 0.94, 0.86]` |
| `foot_y` | 统一脚部基线 `0.825`，与现有演员默认站位一致 |
| `dialogue_slots` | 双人参考位置，x 为 1/3、2/3 |
| `ensemble_slots` | 三人参考位置，x 为 0.25、0.50、0.75 |
| `entrances` | 左右画面边缘的进出参考点，不伪称素材里存在真实房门 |
| `targets` | 合计 37 个已命名物件前停靠点，关联真实对象 ID |

停靠点能力固定为 `approach`，状态为 `standing_targets_only`。这些数据是人工布置的空间参考，尚未接入自动动作编译器；不会因为增加了“书架前”标签就宣称原句已自动生成走到书架的动作。

场景边缘允许角色在进出时部分离开画面；内部 x=0.10–0.90 的本次走位采样保持角色完整。脚部通道下方有留白，字幕继续显示在舞台外，避免遮挡演出。

旧三套家具坐姿依赖旧布局与人物比例，新版不沿用失效的座位校准。旧目录、校准数据和保存版本均保留，可从固定旧目录链接继续打开。
