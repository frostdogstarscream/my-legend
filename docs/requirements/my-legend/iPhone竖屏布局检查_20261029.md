# iPhone 竖屏布局检查与调整 · 2026-10-29

## 基准

以 402 × 874 CSS 像素检查，顶部不预留灵动岛或模拟状态栏。Apple 技术规格为 1206 × 2622 物理像素，本轮按 3 倍缩放换算为布局画布：https://support.apple.com/en-euro/148590 。同时检查 320 × 740、1366 × 900；桌面中的普通产品页面统一为 402px 宽。

检查使用本机 5193 运行中的真实页面和已有作品。没有新建制作任务或新增付费调用。证据目录：`output/playwright/mobile-layout-20261029`。

## 共用布局

- 底栏固定 72px 加底部安全区，五项采用相同的纵向图标/文字排列，不再因为选中状态改变布局方向。
- 页面底部按同一导航高度留出滚动空间。
- 角色弹层标题和确认区固定，中间列表独立滚动。
- 402px 是默认预览宽度，不强制手机扩大到 402px。
- 320px 窄屏保持纵向滚动；滚动至底部，播放页操作区 bottom=647.48，导航 top=668，未被遮挡。窄屏不要求所有信息在首屏内。
