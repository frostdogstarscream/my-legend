# 复合音频链路接入与第八轮验收

## 范围

本轮只处理剧本到广播剧。视觉生成、视觉制作及六例保留集不运行。故事软字数预算、TTS 指令软上限和硬上限保持既定策略。

## 已实现并通过本地验证

1. 独立声音规划与复核使用 2.0 契约。一条原文保持唯一来源，可以包含多个具有逐字依据的声音操作。复核逐行检查完整含义，并逐个核对操作 ID、片段原文和判定。
2. Worker 接收复合编排，将配音、背景与瞬态声音分别生成；声音控制不调用音效模型。实测时间轴保留原文来源和每个操作的实际区间。
3. 重制 API 支持 `regenerate[].operation_id`，可重做单个声音；省略该字段表示重做整行的可听素材。同一行不同操作可以同时选择，整行与局部选择不能重叠。没有声音素材的控制项不能提交生成。
4. 新重制记录固定复用原 AudioArrangement 和 AudioArrangementReview，并核对来源、哈希和所有权，不重新调用规划/复核模型。历史无编排版本维持旧缓存路径；旧作品和媒体不覆盖。
5. 跨作品音效素材库已经接入。按用户范围和完整生成请求精确匹配，WAV 文件不可覆盖，SQLite 保存索引和审核状态。新素材以 pending 入库，本机内部试用允许复用 pending；命中不调用音效供应商，不代表人工听审通过。
6. App 支持新版字幕时序及声音片段列表，可定位、选中单个声音重制。控制项仅显示执行记录。作品页暂缓新的视觉制作入口，保留历史视频访问。
7. 播放接口和下载核验支持时间轴 2.0。独立 PCM 审计通过只读内存映射逐项重算背景范围、音量变化、停止、对白衰减与混音，结果仍引用原始剧本来源与 operation_id。
